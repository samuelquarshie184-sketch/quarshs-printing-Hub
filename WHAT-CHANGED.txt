HOW TO UPLOAD
1. Unzip this. You get a folder called quarshs-app.
2. On GitHub (branch main): Add file > Upload files.
3. Drag the CONTENTS of that folder (css, js, and the 3 files) onto the page.
   Drag the items inside the folder, not the folder itself.
4. Commit message: v1.10.0 storage headroom
5. Wait for Vercel to say Ready, then refresh the app twice on each device.

Nothing in here touches Supabase. Nothing needs the SQL editor again.
